# 抖音世界书

根据 Figma「世界书首页」（节点 `7508:97649`）与「世界书创作页 / 未发布-空白态」（节点 `7510:15786`）实现，使用 React 和 Vite，图片与图标来自设计稿的原始 PNG 导出。

```bash
npm install
npm run dev
```

本地预览：http://localhost:5173

```bash
npm run build
npm run preview
```

首页支持故事/设定与角色两个创建入口、示例预览、世界书分类筛选、搜索及加入/取消加入。首页路径为 `#/`；点击「去创建」进入 `#/create/world` 或 `#/create/character`，两个入口均使用现有世界书创作页。点击创作页的标志可返回首页。

每次进入或刷新创作页，创建新的空白世界书：标题为「未命名」，词条、简介、章节、资料和对话均为空，演示用限免星光重置为 1500；不会自动载入旧稿、旧额度或预填 Mock 词条。当前创作过程仍自动记录到 localStorage。支持世界书重命名、封面上传、目录搜索与切换、词条创建、文档编辑、资料引用和 Markdown 导出。

AI 助手目前使用本地引导回复，尚未接入模型服务。附件只保存文件信息；发布操作只保存本地版本。

点击「我有完整的 IP 作品或资料」直接发送提炼请求，并按 Figma 节点 `7510:89863` 显示上传卡片。支持多文件选择、文件夹选择、文件拖放、抖音作品链接收集，以及资料增删、排序和提交。原始文件保留在当前页面会话中，文件信息加入资料库；尚未对接上传及解析服务。

选择文件后的卡片按节点 `7510:91051` 展示：上传入口横向排列，列表显示真实图片或视频缩略图、文件名称及大小/来源。支持拖动、方向键及按钮排序、单项和全部删除，点击「确认」提交；图片和视频可打开预览。

助手每次回复前按节点 `7540:186528` 展示可展开的处理步骤与实际经过时间；处理完成后收起步骤再显示回复。上传确认后保留只读文件卡，按节点 `7565:102403` 显示星光消耗确认卡，支持重新选文件与再次确认。新对话会取消尚未完成的处理。

当前处理步骤由本地计时模拟，展示任务状态；费用暂按每份资料 90 星光估算，每次新建世界书的演示限免额度为 1500 星光。确认消耗后扣减本地限免额度，banner、待确认卡片和星光弹窗使用同一份剩余额度；额度最低为 0，随世界书保存到 localStorage。同一世界书中开始新对话不会重置额度，重新进入或刷新创作页会创建新世界书并重置为 1500。上传确认、重新选文件和重新生成结果不会扣减，重复确认仅扣减一次。尚未接入真实定价、文件解析、额度查询或付费扣费服务，不会产生真实费用；接入后应由后端返回余额、估价与扣减结果。

星光卡再次确认后，按节点 `7540:193986` 经处理展示提炼完成回复，沿用设计稿中的《灵笼》示例与三类知识汇总。底部支持复制结果、经处理重新生成示例，以及可切换的赞/踩反馈；已确认的消耗卡只读，不显示“已确认”文字，限免 banner 保留并更新剩余额度。当前 56 条知识及事件、角色数据均为固定设计稿文案，尚未解析上传材料；后端接入后应返回真实结果与可导入数据。

所有助手回复（普通对话、上传卡、消耗卡、提炼结果）完成后都显示复制、重新生成、赞、踩四个操作。复制包含正文与资料信息；赞/踩互斥且可取消。重新生成在原消息位置先展示处理步骤再返回内容，保留文件顺序与卡片提交状态，不生成重复的上传或付费确认卡，不重复扣减额度。

按节点 `7713:33761` 准备 20 个可编辑的《灵笼》模拟词条，涵盖世界设定、角色档案、剧情事件与关系网，物种和空间设定支持分层目录。只有确认写入后才加入当前世界书；文稿展示概述、分级章节、来源及贡献者，编辑章节会同步词条正文，Markdown 导出保留内容。

在助手中输入「写入词条」或「确认导入」，处理完成后将示例写入左侧目录和文稿，自动打开「马克」，并展示可点击的结果卡；点击任意结果打开对应文稿。「写入马克词条：新的内容」或「写入当前词条：新的内容」更新指定词条的概述。「写入词条 新角色：角色内容」创建指定名称的新词条。重复导入保留已有正文，不产生同名重复词条；重新生成只重放回复，不重新写入或消耗星光。开始新对话、返回首页或退出创作页会取消未完成的写入。20 个示例与提炼回复中的 56 条知识、首页示例列表均为演示数据，尚未接入实际模型、文件解析或后端写入服务。

空白世界书和已有词条的世界书，均可按节点 `7558:205720`、`7558:207243`、`7558:206422` 通过模拟对话创作，不必先提炼资料。输入「帮我创建一个角色」，助手先询问身份、性格与世界关系；继续发送「幸存者，很孤僻，什么位置都行」等设定，会整理成草稿并询问是否写入。也可从「我只有一个点子」或世界背景开始，逐轮补充世界设定。可多轮补充或用「叫他阿尘」改名，最后输入「好的」「确认」或「写入词条」写入当前草稿；「修改马克的性格……」等指令可准备已有词条的补充草稿。对话阶段不改文稿，处理结束后才更新目录和文稿，并显示单个词条结果卡。

对话草稿的首次写入和已有词条后的写入，在处理状态旁持续展示「感谢贡献内容，本次10星光平台承担」，完成后仍保留。10 星光是设计稿的演示金额，写入不会扣减限免额度；重新生成仅重放结果，不重复写入。新对话清除待写入草稿并取消未完成处理。上述对话、角色展开与写入均为本地模拟，不接入真实模型或计费服务。

消耗确认卡按更新后的节点 `7565:102403` 展示「共提炼 {资料数量与类型}，需消耗 {估价} 星光。你有 {估价时剩余额度} 限免星光可用于抵扣」，确认和重新生成后文案保持一致；顶部限免额度继续同步扣减。平台承担提示固定在处理状态右侧，分割线高 10px。发布按钮悬停或键盘聚焦时，按节点 `7504:87607` 展示共创与星光奖励气泡，配图使用设计稿原始 PNG，点击仍打开本地发布表单。

消耗卡按钮组左侧显示原稿星光图标及抵扣后的消耗值：`max(0, 提炼估价 - 估价时限免余额)`。足额抵扣显示 0，部分抵扣显示差额，没有限免额度显示原价；确认和重新生成后保留本次估价的显示值。当前仍为本地费用演示，差额不触发真实付费。

按节点 `7522:182034`，限免不足时消耗卡提示「剩余 {额度} 限免星光不足抵扣，请充值后继续」，按钮变为「充值并确认」。点击按节点 `7540:188078` 打开充值星光弹窗，显示差额、余额、可选档位、自定义金额、支付图标及原稿二维码；选档位同步右侧价格。充值档位与余额使用同款蓝色星光PNG，差额使用蓝色。默认选择足以抵扣差额的首个档位，差额80时默认100星光（1元）。点击二维码模拟微信扫码成功：关闭弹窗、所选星光到账、自动确认提炼并展示处理步骤；处理完成后扣减费用并展示提炼结果。第二场景余额先由0变100，提炼90抵扣限免10、个人扣80，最终余额20；重复点击与重新生成不重复到账或扣费。自定义金额按每元100星光演示，额度不足时不能模拟成功。仅关闭弹窗不充值、不扣费，实际手机扫码不会触发回调；当前尚未接入真实支付、扫码状态查询和充值服务。

有文件时「全部删除」始终显示，不依赖悬停；提交后保留置灰文字，无法修改已提交文件。

对话框限免 Banner 按更新后的节点 `7510:15786` 使用深色渐变标签及原稿白色 PNG 字样，初始文案为「恭喜获得 1500 限免星光，可用于创建当前世界书」。第一次实际扣减限免星光前，聊天、上传、重新选文件和平台承担的词条写入均不改变文案；确认提炼扣减后仅显示「剩余 {剩余额度} 限免星光」。消耗状态与余额共同保存到世界书，新对话保留，进入或刷新创作页随新世界书重置。

限免星光耗尽后直接隐藏Banner。确认消耗会用完限免余额时，在开始提炼时就隐藏，无需等待处理完成；第二场景充值成功后自动确认提炼时同步隐藏。仅打开或取消充值弹窗不会隐藏Banner。第三场景从未领取限免，不展示此Banner。充值成功Toast按节点 `7864:218446` 使用浅绿色背景、绿色边框、6px圆角、原稿20px成功图标及14px半粗文字，文案为「充值成功，已到账 {充值额度} 星光」。

首页底部悬浮「演示场景」切换器提供三种演示：限免充足（1500）、限免不足（剩余10）、个人星光 / 平台承担（无限免，个人星光1200）。所有场景进入或刷新时输入框统一留空，不预填提炼请求；用户可自行输入或点击引导卡片开始。第二、第三场景按节点 `7864:218037` 展示「我的项目」区域及《灵笼》草稿，封面使用设计稿原始PNG；已有草稿时隐藏故事和角色两张「去创建」卡，通过「新建项目」创建新的世界书。第一场景保留两张创建卡。首页个人余额跟随场景，第三场景显示1200。

第二场景从《灵笼》草稿进入，URL 增加 `draft=linglong`，载入世界设定、马克、冉冰、猎荒小队返回灯塔4个可编辑词条，默认打开马克。右侧展示历史写入对话和已添加、尚未确认的模拟补充资料，初始不展示消耗卡。点击文件卡「确认」后，经处理才展示星光不足卡：提炼90、抵扣10、差额80；点击「充值并确认」打开充值弹窗。Banner 从打开草稿起显示「剩余 10 限免星光」，上传确认不会扣费；限免标签横向内边距为6px。

任一场景的「去创建」或「新建项目」均进入新的空白世界书，不加载草稿词条和历史对话；场景随 URL 的 `scenario` 参数进入创作页，刷新重置到对应演示起点，首页保留上次所选场景。第三场景从「新建项目」开始，个人余额1200，不显示限免Banner，按节点 `7540:202353` 展示纯提炼费用；确认一份资料从个人余额1200扣至1110，右上角与余额弹窗同步，重复确认及重新生成不再扣费。随后发送「帮我创建一个角色」、补充设定并确认写入，显示平台承担提示，不扣个人余额。第三场景也可打开《灵笼》草稿继续编辑，提炼遵循个人余额扣费逻辑。直接访问不带场景参数的创作页仍为空白、1500、无预填对话。草稿与对话为固定本地演示数据，尚未接入后端草稿列表或恢复服务。
